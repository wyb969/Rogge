# ROGGE 趣味性讨论：先验证决策，再扩充内容

日期：2026-11-06（北京时间）。本文件为设计建议，没有实施新的玩法，也没有玩家测试数据。

## 已通过代码确认的基础

- 当前卡池与装备定义对应 21 种卡。选卡三选一，抽取逻辑已尝试同时提供持有装备升级与新装备；每局已有重选。
- 芭蕉扇 `aim_direction()` 已读取冲刺方向 / 最后移动方向，不需要再次实现“冲刺定向”。五级冷却为 0.7203 秒，气流持续 0.52 秒。
- 黑洞自动在附近目标方向产生，至少离玩家 88 单位；普通怪可被牵引，Boss / 试炼敌人有位移限制。
- 灼烧与中毒可以被风各追加一跳；同次风每目标去重，不额外传播，不递归触发状态和吸血。
- 踏风徽记已在冲刺完成位置产生范围攻击；回响火种通过击杀充能。因此工程已有把移动和输出连接起来的基础。
- 暴击眼镜五级为 100% 暴击、200% 暴击伤害。是否使直伤成为优势路线，需要与状态流做同条件比较，不能只凭倍率下结论。
- 宝囊精已提供追击目标与重选补充；天气、怪物主题、神兽、试炼也已存在。

核对入口：`script/pasue_menu.gd`、`script/banana_fan.gd`、`script/black_hole.gd`、`script/run_variety.gd`、`script/critical_glasses.gd`。

## 当前最值得验证的假设

内容增加未必让玩家做出更多有趣决定。可能的瓶颈是：玩家能感受到伤害和特效增加，却不容易说清楚“这局采用什么打法”“刚才为什么打得漂亮”“下局想试什么不同选择”。这是设计假设，需要观察真实试玩验证。

可尝试的方向是“靠冲刺、站位与装备组合操纵怪群的生存肉鸽”。它复用现有系统，也能给移动操作明确价值。暂不将其定为不可更改的产品定位。

## 三个候选实验，优先做第一个

### A. 让现有组合更可控、更容易看懂

- 选用黑洞、芭蕉扇、毒雾 / 汽油瓶构成三分钟小场景。
- 保留现有朝向机制，先尝试让下一次扇风方向与就绪时机清楚可读；不添加额外必按技能键。
- 用同样怪群分别测试自由输出与主动引怪 / 调整朝向，观察玩家是否能主动复现一次解围或清场。
- 五级高速扇风的爽感与时机决策可能有取舍。先记录实际感受，再决定是否需要不同成长分支；不直接回退已确认的冷却数值。
- 保持异常追加一次性规则和特效预算，避免通过无限连锁制造虚假的强度与性能问题。

### B. 让一局形成可描述的构筑

- 先用现有卡验证三条路线：聚怪控场、异常走位、暴击直伤。
- 目标是玩家拿到关键组合后主动改变站位或选卡偏好，而不只是所有效果同时叠加。
- 优先观察已有选卡与重选是否足够支持组合。核心装备位、替换机制、分支进化仅作为后续候选，不默认上线。
- 同条件比较路线：记录前三分钟生存、清怪、选择理由和画面可读性；不只比较总伤害。

### C. 让追逐与风险成为自愿选择

- 从已有宝囊精入手，验证玩家是否愿意偏离安全路线追击，以及是否能看懂追击收益。
- 可以原型比较“清楚预告的限时机会”与现状；不默认新增多个事件系统。
- 避免把随机伤害、突然加速或无法预判的生成当作挑战。

## 一次原型如何判断

先邀请三至五名不了解方案的人试玩相同的三分钟切片。数量只用于早期定性观察，不构成统计结论。

1. 开始前只给最少操作说明，不提示预期答案。
2. 观察玩家是否主动调整站位 / 朝向，是否能复现一次组合成功。
3. 结束后记录他们认为最有趣、最困惑的时刻，以及下一局想尝试什么。
4. 记录死亡原因是否可解释，敌方攻击是否清楚可见，手机帧时间是否异常。
5. 一次只改变一个关键机制；保留原版对照。感觉无聊时允许删减，不用新增三张卡来补偿。

## 获取创意与审美的工作方式

每轮选择一个战斗参考和一个画面参考，拆成可观察的细节：攻击前停顿、攻击后空当、危险色、拾取对比、音效长短、清场后的喘息。记录其解决的问题、在 ROGGE 中的最小实验与代价，而不是只写“更 juice”。

Astra 可负责比较三个候选方案并给出玩家决策、精彩时刻、取舍和验收标准；Sol 按选定方案实现最小可玩版本与聚焦验证。用户通过试玩判断是否有趣。每轮先验证一个假设，再决定是否投入完整美术和成长内容。
