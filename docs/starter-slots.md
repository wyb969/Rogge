# 开局老虎机 · 20261119-145240

基于 master 的 a3affaf5。正常开局选定角色后转动三轴，领取时才开始战斗。重试保留角色并重新抽取。角色自带卡独立发放，与套装重叠时升到二级。

每次有 30% 概率抽到生机或军械三件套，两套等概率。另 70% 给三件不同的散装，连同角色自带卡也不会意外集齐套装。散装至少有一件攻击装备；纯辅助角色遇到生机套时额外获得一件随行武器。只有套装结果启用流动彩箔。斧头和书本可以从零级正常解锁。

运行 tools/smoke_hero_art.gd 检查四个角色的概率边界、两种实际套装效果、装备等级、领取与重开。Debug 预设继续使用各自的测试装备。
