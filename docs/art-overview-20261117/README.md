## 覆盖范围

从 `project.godot` 的主场景、autoload、鼠标指针与应用图标出发，追踪场景/资源/脚本的 `res://` 引用和 `class_name` 依赖，再根据当前 ID 表展开神兽、技能、试炼的动态路径。覆盖 64 个引用图片文件、28 张装备卡、4 个神兽技能图标、左右玩家帧、9 个普通/奖励敌人资源、Boss/试炼角色、实际武器裁切、金币动画、地面图块和工具栏图标。

总览刻意不把整个素材包的闲置图片放进来。玩家只展示当前左右两组动画；巨蜥与骑士展示实际代码/动画轨道使用的帧。被脚本选中的装饰 `(128,64,32,32)` 是全透明区域，已标明空白，没有补画。

程序特效选取代表时刻：毒雾、黑洞、扇风、爆炸、飞刀、十字刃、圣水、荆棘鞭、符文、脉冲、闪电、神兽攻击/释放光环、回血球、敌弹、脚底光环、盾、骑士剑、流星、泼溅图集及 20 种物种泼溅色。环境截图展示晴雨、积雪、风、冰面、电网/骨架、地雷与金币狂热。**这不是所有动态效果的完整逐帧动画表**；瞬态粒子、字体、音频和 shader 源代码没有伪装成独立像素画。

## 修改建议

1. 用总览评估一致性，或把透明图层放进绘图软件统一设计。
2. 修改要正式放回游戏时，优先编辑 `originals/` 中的原图；PNG 放大使用最近邻，SVG 保留矢量源。
3. 不同图标可能共用源图，某些大图只取一个区域。按清单定位原图与区域，不要把整张总览当作现有游戏贴图直接替换。
4. 主体与书本有运行时材质着色；总览第 08 区展示材质对照。修改源图颜色不一定等于最终屏幕颜色。
5. 程序生成特效需修改清单指向的脚本/shader。透明快照用于设计沟通，不会自动改变实际特效。

## 检查与限制

- 原生 Godot 4.7 Compatibility 渲染了本次环境/FX 样本；没有改游戏业务代码。
- 资源覆盖检查：64 / 64 引用图片都对应至少一个总览项；146 项坐标全部落在画布内。原图在 ZIP 中按 SHA-256 校验。
- 检查中文、英文、数字标签渲染；使用支持中英文字形的 Noto Sans CJK，避免项目 fallback 字体缺少 ASCII 的问题。
- 两张选卡版式图沿用当前提交中已有的验证截图，并在总览中标为“仓库验证截图”；其余截图是本次原生采集。
- 捕获进程有原先的退出资源/GL 清理警告；不把这次美术采集描述为全套测试或浏览器/手机 FPS 验证。
