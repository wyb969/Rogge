# 战斗数值第一版 · 2026-11-15

本次从master `204f7d8` 开发，目标是让开局能清怪、后期普通构筑仍能推进，同时收敛斧头和枪械异常增长。没有把每个敌人固定成必须多次命中；暴击、成型组合、低血敏捷怪仍允许快速击杀。

## 代码确认的问题与调整

| 项目 | 原值/行为 | 新值/行为 |
|---|---|---|
| 斧头初始伤害 | 10 | 14 |
| 斧头每次升级 | 当前伤害乘角色等级二次系数，重复选取指数膨胀 | 增加8+0.6×角色等级，等级贡献到30级封顶；卡牌继续增长 |
| 枪械基础伤害 | 每次增加10×新枪械等级，5级为165 | 15+10×枪械等级，5级65；随机附加5～15保留 |
| 枪械射击间隔 | 每级减0.08秒，最低0.05秒 | 每级减0.06秒，基础最低0.22秒；休整冷却仍有效，最终最低0.12秒 |
| 普通追击怪基础血量 | 34 | 42 |
| 壮硕追击怪血量 | 42 | 52 |
| 坦克血量/减伤 | 125 / 45%，等效227 | 90 / 25%，等效120 |
| 怪物等级血量系数 | 1+0.08L+0.008L² | 1+0.10L+0.002L²，L最多40 |
| 攻击卡血量系数 | 每张+7%，无上限 | 每张+2%，最多计算20张 |
| 时间血量系数 | 每分钟+6%，无上限 | 每分钟+6%，最多计算5分钟 |
| 分关血量系数 | 1 / 1.38，之后不再分关 | 1 / 1.22 / 1.32 / 1.42 / 1.52 / 1.62 |

攻击卡仍记录真实数量；只对敌人血量公式的贡献封顶。没有引入扫描装备/DPS后实时抬高敌人血量的机制。敌人攻击力、刷怪频率/数量、Boss血量、精英1.75倍、难度0.5/1/1.5倍率、试炼、敏捷怪20血上限均保持原逻辑。升级文案直接读取同一计算函数，347项卡牌预览检查通过。
