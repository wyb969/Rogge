# ROGGE 开发交接

## 2026-11-19 锻造动作与拖拽

试玩版本 20261119-172805，基于 e6d4862，沿用 feature/card-forge-20261119。每次锻造等待 1.5 秒，炉体跟随三声落锤晃动，在动作结束时按选定的主卡和副卡结算一次。升级结算展示实际产出品质及一次局部金色闪光。四段原创音效共用 SFX 设置，保级与降级各有提示音。

forge_drag.gd 处理牌堆到槽位、槽间移动或交换、拖回牌堆和取消，沿用卡片 UID。手机横划翻牌、向上拖入槽位，点选与键盘操作仍可用。forge_screen.gd 管理等待锁，forge_feedback.gd 管理原创音效与金光。新版专项 tools/smoke_forge_drag.gd 覆盖鼠标和触摸、旋转屏幕、重复输入和离场取消。实际 Web 导出包通过该组 15 项、原锻造 45 项和卡片战斗 182 项检查；画面使用 Godot 原生渲染核对，尚未在手机真机验证。

## 2026-11-19 卡片品质与关后锻造试玩

Godot 4.7，版本 20261119-165223。正式分支为 master。本轮试玩基于 feature/starter-rerolls-20261119 的 edce3ba，在 feature/card-forge-20261119 上开发。更早的发布记录与架构说明见[历史交接](AI_HANDOFF-history-20261116.md)。

- 正常入口沿用选角和初始装备老虎机。每张技能卡独立保存品质与编号。初始装备的青、紫、粉概率分别为 80%、18%、2%。角色固定特性从青色开始，普通升级给青或紫。橙色和橙色之后的连续强化来自锻造。
- 28 种卡共用 forge_inventory.gd 和 forge_stats.gd。张数驱动已有的数量、档位和组合条件。每张卡的数值权重依次为 0.8、1.2、2、4；橙色每次成功强化再加 0.5。战斗、升级卡、局内词典与锻造预览复用同一组计算。
- 关底吸取经验金币和回血球，至少升级一次。所有待选卡结算完再打开锻造。可献祭零至两张任意种类的卡。金币和副卡在有效尝试时消耗一次。粉色起可能降一档。最后一种独立攻击受到保护，拆套装或失去技能会提前提示。
- 一张副卡的基准价格取当关实际金币收入的三分之一（有分关最低价）；零张和两张副卡的价格系数为 1.5 和 0.65。钱包随本局保留，花费不回扣经验。每关按锻造结束时的装备评分发放无尽的永恒，速度最多额外贡献约 12%。真通关追加一次奖励。
- 跨局材料和炉级保存在 user://rogge_forge.cfg。首页 Debug 的「锻造试用」使用临时库存，不写正式存档。Godot 原生渲染的[操作截图](screenshots/card-forge-20261119.jpg)展示异种献祭。
- 核心回归脚本为 tools/smoke_forge.gd（45 项）和 tools/smoke_forge_stats.gd（182 项）。前者覆盖完整结算与重新开局，后者检查全部卡种、实际投射伤害与可逆加成。发布前对导出 PCK 运行两组检查，并运行 python tools/audit_localization.py。手机尺寸验证使用桌面渲染，未测手机真机。
